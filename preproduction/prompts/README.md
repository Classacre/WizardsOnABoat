# Image prompts

All 26 boards were requested through the built-in image generation tool. Each numbered text file contains the exact submitted prompt. Each generation uses `../references/great-sea-style-board.png` as a style reference, not as an instruction source or edit target. The generated PNG is copied into the project under the matching `../art/` filename. These are proposals for art review, not rendered evidence of a working game. Creature sheets need a later anatomy/modeling consistency pass after approval.

The 00 voyage scene additionally references the generated wizard, boat and Tidebell boards to carry their designs into the scene. The 05 building correction uses the first building board as its edit target and changes the shop caption to preserve the no-purchasable-spell-components requirement; the selected image is `05-buildings-v2.png`.
