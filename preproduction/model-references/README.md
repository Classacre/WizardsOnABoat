# Wizards on a Boat - model reference collection

51 complete-subject, single-view PNG images derived from the approved visual direction. Created with the built-in image_gen tool.

## Use

Open index.html to browse and filter the collection, then use the individual PNG for the subject you want to generate. Submit one PNG per model. Tripo can segment the generated complete object into parts; separate exploded-part images are not needed.

These are image references, not generated meshes or rigged assets. Rigging, animation and Godot import validation remain future production work.

prompts.json preserves the exact prompts, original-board names, dimensions and image checksums. model-coverage.json maps all 30 existing GLBs to their replacement reference. Wizard colour and pose variants share wizard.png; boat_sail.glb is covered by the complete boat.png.
