# Third-party world technology

* `terrain_3d/`: Terrain3D **v1.0.2-stable**, downloaded from the maintainer's [release](https://github.com/TokisanGames/Terrain3D/releases/tag/v1.0.2-stable). MIT license retained at `terrain_3d/LICENSE.txt`. Runtime terrain uses its sparse heightmap regions, clipmap geometry, LOD and collision. `shaders/terrain.gdshader` adapts the upstream `extras/shaders/minimum.gdshader`; the geometry and normal reconstruction remain upstream code, with game-specific palette shading added.
* `boujie_water_shader/`: source subset pinned to **25f3c2da458e0a4f65bdb5903dc068b050930c06** from [Chrisknyfe/boujie_water_shader](https://github.com/Chrisknyfe/boujie_water_shader/tree/25f3c2da458e0a4f65bdb5903dc068b050930c06). MIT license retained at `boujie_water_shader/LICENSE.md`. Runtime ocean extends its actual ring mesh/stitched LOD generation. The upstream class is renamed `BoujieOceanGeometry` and editor icons removed; retained wave resource and water shader document the source model. Game shader and CPU queries adapt its Gerstner function, adding inverse horizontal-displacement queries, biome-aware depth colors and procedural foam.

No FFT simulation or GPU readback is used. The first bounded 1,024m world allocates 16 Terrain3D regions of 256 by 256 samples, including submerged terrain. The extension and runtime height import were tested with Godot 4.7.2 on Windows. Full-world heightfield collision supports crews away from the host camera. Generated world geometry is separate from authored character/building/boat models.

Runtime adaptation sets `free_editor_textures=false`: an unsaved generated asset list has no disk path and the upstream default otherwise attempts to load an empty resource. Terrain3D 1.0.2 still emits one engine deprecation warning for `instance_reset_physics_interpolation`; it does not prevent collision, rendering, or the world tests.
